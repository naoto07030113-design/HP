# MATCHA MOOD モバイルオーダー（デモ）

メニューデザイン「MATCHA MOOD」をもとにしたモバイルオーダー Web アプリのデモです。
React + Tailwind CSS + Framer Motion（Vite）で構築しています。

```bash
cd matcha-mood
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に静的ファイルを出力
```

## 機能
- スワイプ（タッチ／マウスドラッグ）・矢印ボタン・キーボード ←→ で切り替わる商品ギャラリー
- 商品ごとのテーマカラーへ背景が滑らかに遷移
- サイズ・甘さ・ミルク・トッピングの選択と価格のリアルタイム更新
- サイズに応じた写真の拡縮、選んだトッピングの写真チップ表示
- カート追加時の「写真がカートへ飛ぶ」演出と通知
- カートの数量変更・削除・合計（localStorage に保存）
- 注文確認（受け取り方法・時間・お名前・支払い方法）→ 完了画面

## 画像素材について
- 商品写真は `public/products/` にあり、すべて元のメニュー画像から切り出したものです。
- 写真素材が無いトッピング（白玉・追い抹茶）は、実物写真を作らず「仮素材・画像未提供」と表示します。
- 元画像の解像度が低いため、大きく表示すると写真はやや粗く見えます。正式な商品写真に差し替える場合は同じファイル名で置き換えてください。
