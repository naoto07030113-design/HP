# テスト

`npm test` で実行する（`vitest run`）。CI では lint / 型チェック / テスト / ビルドの順に走る。

ここに置くのは「壊れると業務が壊れる」判断だけに絞っている。
画面の見た目ではなく、**お金・予約枠・権限・個人情報の扱い**を固定するのが目的。

| ファイル | 守っているもの |
|---|---|
| `billing.test.ts` | 会計金額の計算式（サーバーが唯一の計算元） |
| `appointment-conflict.test.ts` | 予約枠の重複判定（ダブルブッキング防止） |
| `permissions.test.ts` | ロールごとの権限と所属院スコープ |
| `validators.test.ts` | 入力スキーマ（合計金額や状態を受け取らないこと） |
| `logging.test.ts` | ログの伏字処理（資格情報と個人情報を残さない） |
| `rate-limit.test.ts` | 未認証エンドポイントとログインの回数制限 |
| `analytics-period.test.ts` | 集計期間の区切り（今月・前月・前期比） |

DB へは接続しない。DB に触る層はモックに差し替えて、判断そのものを確認する。
